The app won't start / shows an error on launch

Make sure you're on Windows 10 version 1809 or later (Windows 11 recommended). Unzip the download fully before running — don't run it from inside the zip.

Windows says the app is from an unknown publisher

That's normal for apps downloaded outside the Microsoft Store. Click "More info" then "Run anyway".

An AI button is grayed out

On-device AI needs a PC with the Windows AI model available. The button disables itself with an explanation when it isn't — everything else keeps working.
