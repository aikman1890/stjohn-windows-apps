# DayPilot — Store Listing

## Description

DayPilot is your on-device AI daily companion for Windows. Capture notes, set
reminders in plain language ("remind me to call Mom tomorrow at 3pm"), and let
the built-in Phi Silica model summarize notes, rewrite them, and pull out action
items — all without anything ever leaving your PC.

## Features

- **Plain-language reminders** — type "water the plants in 2 days at 9am" and
  DayPilot parses the date and time locally, with toast notifications when
  reminders come due.
- **On-device AI note tools** — summarize, rewrite, and extract action items from
  your notes using Phi Silica. Zero cloud calls; works fully offline.
- **Daily briefing + global hotkey** — open with a briefing of notes, today's
  reminders, and overdue items; press **Ctrl+Shift+D** from anywhere in Windows
  to jump straight to quick note capture.
