# FarewellPilot - Store Listing Draft

**Tagline:** The case book for the independent funeral home - arrangements, clocks, contracts, and preneed in one place.

**Price:** $19.99/month

**Description:**
FarewellPilot is the case book for a single-location funeral home, in a category where most platforms will not even publish a price. One file per family: decedent and next of kin, service type, the full status pipeline from first call to closed, and an arrangement checklist built for the case type - vital records, obituary, clergy, cemetery or crematory, merchandise, flowers, music - each item carrying who confirmed it and when, so a second director can pick up any case cold.

Paperwork runs on clocks, not memory. The death-certificate filing window and the preneed deposit window are computed per case from the windows YOU set in Settings from your own state rules - FarewellPilot ships no law and gives no legal advice. Green, orange inside five days, red overdue, every date showing its basis.

The contract ledger itemizes every case - professional services, facilities, merchandise, cash advances - with payments and insurance assignments tracked from filed to paid, a balance that is always current, a receivables aging view, and a printable family statement. The preneed book reconciles itself: every contract against its deposit log, undeposited dollars flagged with the window closing date, ready for the examiner's question. When a service completes, aftercare schedules itself - a week, a month, the anniversary - so the follow-up that brings the next family in the door no longer depends on anyone remembering.

Documents are recorded by local path; family information never leaves the home's PC. No portal, no e-signature upsell, no per-call meter, no network calls at all. A sample case and a sample preneed contract are seeded on first run so the home can see the checklist, clocks, and reconciliation working before a real family is entered.

**Features:**
- Case files with automatic numbering and the full service pipeline
- Per-type arrangement checklists with who/when confirmation
- Paperwork clocks: death-certificate window and preneed deposit window, user-set and basis-labeled
- Contract and payment ledger with insurance-assignment tracking and aging
- Printable family statements
- Preneed book with deposit log and reconciliation view
- Local document vault by file path
- Automatic aftercare scheduling (week / month / anniversary) with a due-this-week view
- Reports: cases by type and month, aging, preneed totals, cash-advance summary

**Privacy:** All data is stored locally on your PC. The app makes no network calls and collects nothing.
